# ERGOSENSE — The Complete Simple Guide

This guide explains our whole project in very simple English.
It is for learning the project, presenting it, and answering judges.

## How to read this guide

| File | Chapters | What is inside |
|---|---|---|
| `01_project_and_problem.md` | 1–8 | The idea, the problem, how it works, workflows, architecture, technology |
| `02_core_technologies.md` | 9–15 | Database, Reinforcement Learning, Generative AI, Networks, Computer Vision, ML, Training |
| `03_code_explained.md` | 16 | The important code, explained piece by piece |
| `04_evaluation_and_business.md` | 17–29 | Competitors, numbers, efficiency, feasibility, SDG 9, novelty, impact, startup, security, failures, limits, future |
| `05_presentation_and_questions.md` | 30–37 + final | Talk script, question bank, "why not", "what if", word list, revision sheets, how to handle any question |

**If you only have 10 minutes:** read Chapter 37 (the last part of file 05).

## Labels used in this guide

| Label | Meaning |
|---|---|
| **FACT** | True about our code. You can open the file and check it. |
| **OUR MEASUREMENT** | A number we measured ourselves by running the project. |
| **EXTERNAL SOURCE** | Comes from outside (a paper, the UN, a company). |
| **TO VERIFY** | An outside fact we believe is true but have not checked from a source. Check it before you say it on stage. |
| **ASSUMPTION** | Something we decided or guessed. It is not measured. |
| **CURRENTLY IMPLEMENTED** | Built and working. |
| **PLANNED / FUTURE WORK** | Not built yet. |
| **NOT MEASURED** | We do not have this number. Do not make one up. |

## Where every number comes from
